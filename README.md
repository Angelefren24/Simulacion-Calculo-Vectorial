
# Simulación de Cálculo Vectorial

## Simulación de Trayectorias de Partículas y Sombreado Térmico en Motores de Videojuegos

### Descripción del proyecto

Proyecto desarrollado para la materia de Cálculo Vectorial del Instituto Tecnológico de Celaya.

Consiste en una simulación interactiva tridimensional que representa el movimiento de una partícula mediante una trayectoria helicoidal dentro de un cilindro, considerando un campo de intensidad luminosa.

### Temas matemáticos aplicados

- Funciones vectoriales.
- Parametrización de trayectorias.
- Vector velocidad y rapidez.
- Longitud de arco.
- Curvatura.
- Derivadas parciales.
- Gradiente de una función escalar.
- Campos vectoriales.
- Conservatividad y rotacional.
- Integrales triples en coordenadas cilíndricas.
- Integración numérica y estimación del error.

### Características de la simulación

- Visualización tridimensional interactiva.
- Movimiento de una partícula sobre una trayectoria helicoidal.
- Representación del gradiente de intensidad luminosa.
- Visualización del campo de iluminación.
- Cálculo de la integral triple.
- Controles de inicio, pausa y reinicio.
- Rotación y acercamiento de la cámara.
- Modo claro y oscuro.
- Visualización de resultados matemáticos.

### Tecnologías utilizadas

- Python
- NumPy
- SciPy
- PyVista
- PyVistaQt
- PySide6
- VTK

### Instalación

Es necesario tener Python instalado.

Descargar o clonar este repositorio y ejecutar el siguiente comando desde la terminal:

```bash
python -m pip install -r requirements.txt
```

### Ejecución

Para iniciar la simulación, ejecutar:

```bash
python "Proyecto calculo vectorial.py"
```

### Parámetros de la simulación

| Parámetro | Valor |
|---|---|
| Radio del cilindro | 4 m |
| Altura del cilindro | 10 m |
| Radio de la trayectoria | 2.5 m |
| Velocidad angular | 2π rad/s |
| Velocidad vertical | 2 m/s |
| Tiempo de simulación | 5 s |
